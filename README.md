# 체험단 매칭 보드 (Creator Matching Board)

브랜드·대행사·셀러가 **체험단 모집 공고 → 지원자 선정 → 제품 발송 → 리뷰 마감 → 성과(CPV·ROI)** 를 한 화면에서 처리하는 무서버 정적 웹앱.

- 빌드 없음 · 서버 없음 · 계정 없음 · 외부 요청 0건 · 데이터는 브라우저 `localStorage`에만
- 떡상 레이더(`../shortform-radar/`)와 같은 패밀리 룩: IBM Plex Sans KR, 라이트/다크, 반응형
- 미리보기: `preview-desktop.png` (보드 1440×900), `preview-mobile.png` (390×844), `preview-brief.png` (공고 생성기), `preview-stats.png` (성과 대시보드), `preview-dark.png` (다크 모드), `preview-mobile-stats.png` (모바일 대시보드), `preview-upgraded.png` (카피 심리학·도입부), `preview-ai-bridge.png` (AI 브리지)
- 업그레이드(2026-11-21): **카피·심리학 엔진**으로 공고문·DM·메일·가이드의 8대 트리거 점수와 추상어·공급자어 교정, **PAS·BAB·AIDA·4U 도입부** 제안, **내 구독 AI 원클릭 브리지**(ChatGPT·Claude·Gemini, 무료 Gemini 키 선택)로 공고 다듬기·광고주 성과 리포트

## 카피 심리학 · 도입부 · AI 브리지

### 1. 8대 트리거 진단 (공고·DM·메일·가이드)

지금 보고 있는 문서를 그대로 진단합니다. 위쪽 문서 탭을 바꾸면 대상도 함께 바뀝니다.

| 그룹 | 트리거 | 목표 | 이 앱에서 보는 것 |
|---|---|---|---|
| **지원** (42) | 희소성·기한 15 · 손실 회피 15 · 초저마찰 CTA 12 | 42 | 마감 시각·잔여 인원, "놓치면" 표현, 신청 방법의 마찰 |
| **신뢰** (43) | 사회적 증거 16 · 권위·실측 14 · 구체적 숫자 13 | 43 | 후기·선정 사례, 실측·인증, 인원·금액·기한의 구체성 |
| **관심** (15) | 호기심 갭 8 · 인지 반전 7 | 15 | 질문·반전으로 첫 3줄을 붙잡는 힘 |

- 점수는 엔진 신호의 가중 평균(0~100). S 75+ · A 60+ · B 45+ · C 그 미만.
- "먼저 채울 빈틈"은 가중치 × 부족분이 큰 순서로 3개만 보여 줍니다.
- 체험단 공고는 판매 페이지가 아니라 **지원 결정** 페이지라서 지원·신뢰에 가중치를 뒀습니다(가중치 합 100).
- 기본 템플릿 공고문은 후기·실측·손실 표현이 없어 **41점(C)** 이 나옵니다. 버그가 아니라 "무엇을 채워야 하는지"를 보여 주는 값이며, 빈틈 3개와 AI 브리지가 채울 곳을 알려 줍니다.

### 2. 추상어 · 공급자어 교정

`최고의·다양한·혁신적인`, `저희는 … 제공합니다`, `매우`, `~되어집니다` 같은 표현을 찾아 대안과 함께 보여 줍니다.

- **[안전 치환 적용]** 은 문법·군더더기만 바꿉니다(`매우 ` 삭제 등).
- `최고의`, `유일한`, `100%` 처럼 **사실을 새로 만들어야 하는 표현은 자동 치환하지 않고** 대안만 제시합니다(표시광고 위험).
- 치환본은 "AI 적용본"으로 저장되고 문서 아래 **[되돌리기]** 로 언제든 자동 생성본으로 돌아갑니다.

### 3. 공고 도입부 4종

캠페인 조건에서 지원자의 망설임·체험으로 얻는 것·근거 숫자를 자동으로 채워 **PAS · BAB · AIDA · 4U** 도입부를 만듭니다.
세 칸을 직접 고치면 그 문장이 반영되고, 비우면 자동값으로 돌아갑니다. **[공고문 맨 위에 넣기]** 를 누르면 공고문 앞에 붙습니다(되돌리기 가능).

### 4. 내 구독 AI 원클릭 브리지

캠페인 조건 · 현재 공고문 · 카피 진단 · 지원자 현황을 하나의 프롬프트로 묶어 **[ChatGPT 열기] · [Claude 열기] · [Gemini 열기]** 로 보냅니다.

- 버튼을 누르면 프롬프트가 **클립보드에 자동 복사**되고 새 창이 열립니다. ChatGPT·Claude는 주소의 `q` 파라미터로 입력창까지 채우지만,
  이 앱의 프롬프트는 4,000자 안팎이라 주소 한도를 넘어 **붙여넣기(Ctrl+V)** 로 안내합니다(그래서 항상 클립보드에 복사합니다).
- AI 브리지는 **모집 공고문**을 다듬습니다. DM·메일·가이드 탭을 보고 있어도 같은 공고문을 보내고, 적용하면 공고문 탭으로 돌아옵니다.
- **개인정보 보호**: 기본값은 지원자 **이름·핸들을 `지원자 A` · `@creator_a`로 익명 처리**하고, 메모·리뷰 링크는 어떤 경우에도 넣지 않습니다.
  이름·핸들이 필요하면 체크박스로 직접 켜야 합니다. 공고문에 공개되는 신청·문의처는 그대로 포함됩니다(공고에 이미 공개되는 정보).
- AI가 준 공고문을 붙여넣으면 **글자 수 · 심리 점수 · 대가성 문구 유지 · 원본에 없는 숫자**를 자동 점검하고, **[이 공고문에 적용]** 으로 바로 넣습니다.
  (날짜 표기는 형식이 달라도 검사에서 제외합니다.)
- **무료 Gemini API 키(선택)**: 키를 넣으면 새 창 없이 이 화면에서 생성합니다. 키는 `localStorage`에만 저장되고 `generativelanguage.googleapis.com`으로만 나갑니다. 키가 비면 외부 요청은 0건입니다.

### 5. 광고주 보고용 성과 리포트

대시보드 숫자 그대로 1장 리포트를 자동 생성합니다(한 줄 결론 · 핵심 지표 · 채널별 · 진행 현황 · 잘 된 점 · 다음 캠페인 제안).
실측/예상 조회수를 구분하고, 환산 광고가치는 "기준 CPM 가정"이라고 밝히며, 새 수치를 만들지 않습니다.
같은 리포트를 AI로 다듬어 **[리포트에 적용]** 할 수 있고, AI가 쓴 숫자 중 원본에 없는 값은 경고로 표시합니다.

## 계산식 (화면에 그대로 노출)

```
지원자 단가      = 원고료 + 제품가
집행 비용        = 선정 완료 이후 지원자의 단가 합계   (모집 지원 단계는 비용 아님)
지원자 포함 예상 = 전체 지원자 단가 합계
총 조회수        = 실측 조회수(리뷰 업로드 이후) + 미제출 지원자의 평균 조회수
CPV              = 집행 비용 ÷ 총 조회수
CPM              = CPV × 1,000
참여율           = (좋아요 + 댓글) ÷ 실측 조회수
환산 광고가치    = 총 조회수 × 기준 CPM ÷ 1,000
광고 환산 ROI    = (환산 광고가치 − 집행 비용) ÷ 집행 비용
매출 ROI         = (직접 매출 − 집행 비용) ÷ 집행 비용
손익분기 조회수  = 집행 비용 ÷ (기준 CPM ÷ 1,000)
```

- 실측 조회수가 없는 지원자는 **평균 조회수로 예상**하며, 대시보드에 `실측 6명 · 예상 4명`처럼 나눠 표시합니다.
- 직접 매출을 비우면 **광고 환산 ROI**를, 넣으면 **매출 ROI**를 먼저 보여 줍니다.
- 기준 CPM 기본값은 8,000원/1,000회(같은 노출을 유료 광고로 샀을 때의 비용 가정)입니다.

## CSV·JSON

**일괄 등록**: 엑셀·시트 표를 그대로 붙여넣거나 `.csv` 파일 선택. 탭/쉼표/세미콜론 구분, 따옴표 안 쉼표, 한글·영문 헤더를 모두 읽습니다.

```csv
이름,핸들,채널,팔로워,평균 조회수,원고료,마감일,리뷰 URL,조회수,좋아요,댓글,메모
뷰티로그,@beauty.log,인스타,1.2만,3.4만,50000,2026-12-05,,,,"DM 응답 빠름, 주소 확인"
```

- 헤더가 없으면 `이름, 핸들, 채널, 팔로워, 평균 조회수, 원고료, 마감일, 메모` 순서로 읽습니다.
- `1.2만` · `3억` · `1.3M` 표기를 숫자로 변환하고, `인스타·릴스·IG` / `블로그·네이버` / `유튜브·쇼츠` / `스레드` 별칭과 `지원·선정·발송·업로드·정산` 상태를 인식합니다.
- 중복 핸들은 가져올 때 건너뜁니다.
- **내보내기**: 지원자 CSV(UTF-8 BOM, 엑셀 호환) · 전체 백업 JSON(캠페인 조건 + 지원자 + 설정) · JSON 불러오기 · 데모 초기화.

## 프라이버시

- 외부 요청 0건: 폰트·아이콘·스크립트까지 전부 로컬 파일입니다. (테스트가 요청 URL을 전부 검사)
- 데모 지원자 12명의 이름·핸들·리뷰 링크·메모는 **전부 가상**입니다. 리뷰 링크는 `example.com`, 메일은 `example.com`, 운송장 번호도 샘플 표기입니다.
- 입력한 값은 이 브라우저 밖으로 나가지 않습니다. 브라우저 데이터를 지우면 사라지므로 `내보내기 → JSON 백업`을 권장합니다.
- **AI 브리지는 사용자가 버튼을 누를 때만** 프롬프트를 클립보드에 복사하고 해당 서비스 창을 엽니다. 앱이 스스로 외부로 보내는 요청은 없습니다.
  프롬프트에는 기본적으로 지원자 이름·핸들이 익명으로 들어가고 **메모·리뷰 링크는 절대 들어가지 않습니다**.
- Gemini 키는 선택 사항이며 `amb.v1.ai`(localStorage)에만 저장됩니다. 키가 비어 있으면 외부 요청은 0건이고, 넣었을 때도 `generativelanguage.googleapis.com` 한 곳으로만 나갑니다.

## 테스트


  콘솔·페이지 에러 0, 404·요청 실패 0, 외부 요청 0, 가로 넘침 0,
  공고문 생성·조건 변경 반영·복사, 보드(검색·채널/마감 필터·드래그·◀▶·상세 저장·추가·2단계 삭제),
  CSV 3건 등록·중복 제외·만 단위 파싱, CSV BOM/JSON 내보내기·JSON 복원, 데모 초기화,
  대시보드 CPV·참여율·ROI·CPM 변경·업로드 확인, 다크 모드 유지, 모바일 레이아웃(칸반 가로 스크롤·리스트 내부 스크롤·모달),
  카피 심리학(8트리거·그룹·빈틈·문서 전환), 추상어 교정(안전 치환·되돌리기), 도입부 4종(직접 입력·복사·공고문에 넣기),

## 알려진 한계

- 캠페인은 한 번에 하나입니다. 여러 브랜드를 동시에 운영하려면 JSON 백업으로 캠페인을 바꿔 가며 쓰거나, 캠페인 선택 기능을 추가해야 합니다.
- 인스타그램·블로그·유튜브의 조회수를 자동으로 가져오지 않습니다(공개 API·약관 문제). 리뷰 링크와 실측 지표는 직접 입력합니다.
- ROI의 "환산 광고가치"는 기준 CPM 가정에 따른 추정치이며 실제 매출이 아닙니다. 매출을 넣으면 매출 ROI를 함께 보여 줍니다.
- 데이터는 브라우저에만 있으므로 기기를 바꾸면 JSON 백업으로 옮겨야 합니다.
- AI가 쓴 숫자는 원본 데이터와 대조해 경고만 표시합니다. 광고주에게 보내기 전에 한 번 더 확인하세요.
- 두 엔진의 프리셋·가중치는 공개 자료 기반 추정이며 A/B 테스트로 검증한 값이 아닙니다. 점수는 참고 지표입니다.
- AI 적용본은 자동 생성본과 별도로 저장됩니다. 캠페인 조건을 바꿔도 적용본은 그대로이므로, 조건이 바뀌면 [되돌리기]로 자동 생성본을 쓰세요.
